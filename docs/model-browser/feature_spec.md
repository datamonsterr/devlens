# Model Browser

## Type

New Devlens feature built from 9router model/provider data.

## Purpose

Let Developers discover available models, Combos, providers, capabilities, and pricing.

## Requirements

- Developer sees Team-available models and Combos.
- Manager sees same browser plus management links.
- Pricing shown from Pricing Overrides or auto pricing.
- Browser is read-only for Developers.

## 9router change

Move model list from local admin utility to Team-aware discovery surface.
