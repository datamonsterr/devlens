# Pricing Overrides

## Type

Modified/new Devlens feature.

## Purpose

Manager controls per-model cost accounting for usage analytics.

## Requirements

- Pricing Override belongs to Team.
- Auto pricing may populate base entries where provider supports it.
- Manual override wins over auto pricing.
- Usage analytics use Team pricing for cost calculation.
- Developer can view prices, not edit.

## 9router change

Turn local pricing config into Team-scoped Manager feature.
