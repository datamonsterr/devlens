# CLI Config Snippets

## Type

New Devlens replacement for 9router CLI auto-config.

## Purpose

Show copyable config for Claude Code, OpenCode, and Codex.

## Requirements

- Snippets use Team endpoint and Developer API Key.
- Existing API Keys never reveal plaintext.
- New API Key creation can immediately fill snippet once.
- Support manual API Key paste into snippet UI.
- Route should be `/dashboard/cli-config`.

## 9router change

Remove CLI writers/checkers and keep copy-paste-only snippets.
